# AI-Powered Tic-Tac-Toe 🎮

A versatile, AI-driven Tic-Tac-Toe game featuring an intelligent opponent. This project offers dual gameplay modes: an interactive, modern web application and a classic command-line (CLI) experience in Python. Built as a practical application of core programming principles following the completion of the **Python Essentials 1** certification.

🚀 How to Run
Option 1: Web Version (JavaScript / HTML / CSS)
No installation required.

Clone or download this repository:

Bash
git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
Navigate to the project folder.

Double-click index.html or open it in any modern web browser to start playing immediately.

Option 2: Command Line Version (Python)
Requires Python 3.x.

Open your terminal or preferred Python IDE (VS Code, PyCharm, IDLE, etc.).

Navigate to the project folder:

Bash
cd path/to/repository
Run the Python script:

Bash
python main.py

## 🌟 Features

* **Smart AI Opponent:** Evaluates board states to challenge players in real time.
* **Dual Interface Options:**
  * **Web Version:** Fully responsive in-browser experience powered by JavaScript (no backend or Python installation needed).
  * **CMD / CLI Version:** Classic terminal-based version written in Python.
* **AI-Assisted UI:** Modern front-end interface styled with HTML and CSS using AI design tools.
* **Lightweight & Fast:** Zero external dependencies for both web and Python runs.

---

## 🛠️ Tech Stack

* **Python:** Core programming logic & CLI terminal game.
* **JavaScript:** Front-end AI logic and interactive DOM manipulation.
* **HTML5 & CSS3:** Web interface layout and styling (designed with AI assistance).
